01. chezmoi on all machines (sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply git@github.com:$GITHUB_USERNAME/dotfiles.git). See ~/to_install/01_cli_tui_tools_to_install/02_darwin_linux_cli_tui_tools_to_install/01_darwin_linux_all_machines_cli_tui_to_install/00_curl_to_bash_all_machines_cli_tui_tools.txt
02. Install webi brew (try on all *nixy machines, else localhost *nixy machines) (curl -sS https://webi.sh/brew | sh). See ~/to_install/01_cli_tui_tools_to_install/02_darwin_linux_cli_tui_tools_to_install/01_darwin_linux_all_machines_cli_tui_to_install/00_curl_to_bash_all_machines_cli_tui_tools.txt
3a. nerd_font_name="VictorMono" bash <(curl -fsSL https://raw.githubusercontent.com/monoira/nefoin/main/install.sh). Needs fontconfig which is usually missing on default macOS installs
3b. If 3a does not work, for VictorMono NF on Linux localhost only (brew bundle install --file= ~/to_install/01_cli_tui_tools_to_install/00_linux_only_cli_tui_tools/00_linux_only_localhost_cli_tui_tools_to_install/Brewfile_linux_only_local_host_cli_tui_tools_to_install.txt) and do a Symlink (if not already present) ~/.local/share/fonts to ~/.local/opt/brew/share/fonts
04. Install Flatpak (on Linux localhost only) if not already installed in the base distro
05. Install Flatpak apps (Linux localhost only). (cat ~/to_install/02_gui_tools_to_install/linux_only_gui_tools_localhost/flatpak_apps_to_install.txt | xargs -n1 flatpak install -y)
06. Install Pixi (all OS, all machines). curl -fsSL https://pixi.sh/install.sh | PIXI_HOME="$HOME/.config/pixi" bash (for *nixy installation. Windows installation uses different syntax). See ~/to_install/01_cli_tui_tools_to_install/02_darwin_linux_cli_tui_tools_to_install/01_darwin_linux_all_machines_cli_tui_to_install/00_curl_to_bash_all_machines_cli_tui_tools.txt and do `pixi global sync`

08. Install Rustup (all OS, all machines). curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh. See ~/to_install/01_cli_tui_tools_to_install/02_darwin_linux_cli_tui_tools_to_install/01_darwin_linux_all_machines_cli_tui_to_install/00_curl_to_bash_all_machines_cli_tui_tools.txt

10. Now cargo binstall -y (all OS, all machines) useful rust packages. cat ~/to_install/01_cli_tui_tools_to_install/01_all_os_cli_tui_tools_to_install/01_all_os_all_machines_cli_tui_tools_to_install/02_cargo_packages_all_os_all_machines_to_install/02_cargo_binstall_all_os_all_machines.txt | xargs -n1 cargo binstall -y
